# LeetCode C++ Solutions

Solutions are grouped into three difficulty folders: Easy, Medium, and Hard.

## Naming format

`<sequence>_LC<problem-number>_<ProblemTitle>_<Difficulty>.cpp`

Example: `16_LC041_FirstMissingPositive_Hard.cpp`

## Contents

- Easy: 9 solutions
- Medium: 5 solutions
- Hard: 2 solutions

Each file contains a LeetCode-compatible C++ class implementation.
Linked-list problems use LeetCode's `ListNode` definition; commented local definitions are included in those files.
